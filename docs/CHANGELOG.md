# 변경 기록

## 2026-11-11 · 0.1.0

- 프로젝트와 앱 이름을 Noesis(노에시스)로 확정했다.
- 기존 자동 투자 프로젝트에서 UI·예시 자료·제품 요구사항을 별도 저장소로 분리했다.
- 독립 실행을 위해 공개 프런트엔드를 React·TypeScript·Vite로 구성했다.
- 화면 이름, 로그인 예시, 메타데이터를 Noesis로 변경했다.
- 홈·검색·관심 종목·차트·기간별 결과·뉴스/공시·계정·내 정보 시안을 포함한다.
- README, 제품 요구사항, 구조 문서, 브라우저 캡처, 빌드 CI를 작성하고 public 저장소에 게시했다.
- 실제 시세/모델/인증/DB/계좌 연결은 아직 구현하지 않았다.

- 사용자 요청에 따라 기존 UI 미리보기, 제품 기획·변경 이력, 제품 조사 자료를 Desktop/Noesis의 `.local/`로 이동했다. SIMA에는 제품 기획 절·UI 변경 기록·미리보기 복사본을 남기지 않았다. 이후 작업 기준 폴더를 Noesis로 변경했다.
- 독립 프런트엔드 타입 검사·빌드와 360/390/768/1440px 브라우저 검증을 통과했다. 네 로그인 경로·프로필·검색/이력·차트·뉴스·공시를 확인했고 브라우저 오류·외부 요청은 없었다. README 상대 링크와 공개 파일의 비밀값·호스팅 식별자 포함 여부를 점검했다.
- GitHub 프로필 소개 표와 고정 프로젝트의 DNB 항목을 Noesis로 교체하고 Photogram을 유지했다. GitHub Actions 빌드 성공을 확인했다.
